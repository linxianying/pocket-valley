## 🇨🇳 中文说明

一款柔和绘本水彩风模拟经营农场小游戏，打开浏览器即可直接游玩，支持**开局角色与农庄定制、四季天气、荷花池垂钓（含极品灵鱼）、极品植物变异、小屋厨房 26 道料理、拍立得拍照分享、64 项交互式图鉴、农场萌宠、阳光牧场**，以及**中/英文切换、移动端触屏手柄、PWA 离线安装与 Google Drive 云存档同步**。

### ✨ 特色玩法

- **🎨 开局弹窗定制农庄与角色**
  - 新开局直接弹出居中配置对话框，自由选择**男孩 / 女孩**角色与 **4 套对应田园穿搭**（女孩 4 款碎花裙；男孩背带装、田园衫、森系马甲、暖织开衫）。
  - 可选 **4 种田园小屋样式**（红瓦奶油小屋、森林绿瓦木屋、薰衣草童话屋、蜂蜜茅草农舍）与 **3 种农庄地图布局**（荷花东池「水池靠右」、荷花西池「水池靠左」、溪畔双田「水池居中」），支持实时预览；进入游戏后主界面保持简洁，所有外观换装与偏好设置均收纳在顶部「⚙️ 设置」弹窗中随时修改。
- **🏡 田园农庄**
  - 开垦农田、种植 **10 种农作物**（芜菁、小麦、樱桃萝卜、胡萝卜、小番茄、甜玉米、草莓、蓝莓、南瓜、杨桃），其中小番茄、甜玉米、草莓、蓝莓支持成熟后重复收获。
  - 可升级**锄头**与**浇水壶**，使用**镰刀**清理杂草，并摆放**自动洒水器**与夜晚发光的**田园提灯**。
- **🌸 四季轮转与动态天气**
  - **春夏秋冬四季**（每季 14 天），每个季节都有对应的应季加成作物、水彩配色与氛围粒子（花瓣、夏夜萤火虫、秋日枫叶、冬日飞雪）。
  - **5 种天气**（晴天、多云、微风、细雨、雪天）与明日天气预报；细雨天会自动浇灌农田，并配有清晨→白昼→黄昏→夜晚的渐变光影。
- **🎣 荷花池垂钓（17 种水产，含 3 种小概率极品灵鱼）**
  - 在荷花池畔甩杆钓鱼，收集 **17 种手绘水彩水产**（常见 4 种 · 少见 4 种 · 稀有 4 种 · 传说 2 种 · **✨ 极品灵鱼 3 种**：霓裳仙鲤、冰晶龙鱼、凤羽金龙），各具专属季节/天气/时段出没条件与历史最重纪录；极品灵鱼仅以极小概率现身，且不会被普通鱼类菜谱误消耗。
- **🌸 极品植物变异奇观（小概率伴生）**
  - 收获成熟农作物时有极小概率触发植物变异奇观，伴生出 **4 种极品奇珍植物**（琉璃水晶玫瑰、鎏金麦穗王、月光幻莓、星辰雪莲），拥有专属水彩手绘插画，可用于烹制顶级极品料理。
- **🍳 小屋厨房与 26 道料理（含 4 道极品御膳 + 大厨奇迹）**
  - 升级厨房后支持按 **全部 / 田园主菜 / 鲜鱼海鲜 / 甜品烘焙 / 👑 极品料理** 5 大分类筛选；用极品灵鱼与极品变异植物可烹制 **4 道极品料理**（星辰琉璃花露羹、凤羽玉露佛跳墙、霓裳仙鲤御膳刺身、口袋山谷奇迹满汉席），烹制普通菜谱时也有小概率触发「✨ 大厨灵光一闪」额外获赠 1 份！
- **📸 极品奇遇拍立得拍照与分享**
  - 每当钓到极品灵鱼、收获变异极品植物、做出极品料理或触发大厨奇迹时，自动弹出**绘本风纪念拍立得弹窗**（左侧自动抓拍农庄实时画面，右侧展示高清手绘水彩奇珍与山谷日期邮戳），支持**快门重拍、保存 PNG 纪念照、一键复制分享文案/图片与系统分享**；也可在图鉴已解锁详情页随时再次拍照分享。
- **📖 交互式绘本图鉴（64 项收集，可点进详情）**
  - 点击顶部 **📖 图鉴**（或按快捷键 `F`）查看总收集进度条与 **4 大标签页**（**🐟 鱼类 17 · 🍳 菜谱 26 · 🌱 植物 14 · 🐮 牧场与宠 7**），点击任意卡片均可查看详情、关联菜谱与一键拍照分享。
- **🐾 农场萌宠与 🐮 阳光牧场**
  - 免费领养**三花猫**、**柯基犬**或**垂耳兔**随行散步互动；穿过东侧木门（或点顶部按钮）前往阳光牧场饲养小母鸡、小白鸭、软绵羊与花奶牛，每日收获鸡蛋、鸭蛋、羊毛与鲜牛奶。
- **💾 实时双备份存档与 Google 云同步**
  - 操作后 1 秒内自动保存到浏览器本地（`localStorage` + `IndexedDB` 双重备份），支持 JSON 导出/导入，也可配置个人 Google OAuth Client ID 同步至 Google Drive 私密应用空间（`appDataFolder`）。
- **📱 移动端适配、PWA 离线与中英双语**
  - 支持点击地图自动寻路交互；内置本地 `tailwindcss.js`、`manifest.json` 与 `sw.js`，零外链依赖，可添加到主屏幕离线畅玩；在「⚙️ 设置」中随时切换 `中文 / EN`、虚拟手柄与音效开关。

### 🎮 操作说明

| 按键 / 操作 | 功能说明 |
| --- | --- |
| `WASD` / `方向键` / 点击地图 | 移动与自动寻路互动 |
| `左键点击` / `Space` | 使用当前工具（耕地、浇水、播种、甩杆、钓鱼按住拉杆） |
| `E` / `右键点击` | 智能互动（采摘、收蛋挤奶、抚摸动物/宠物、进屋/开店、鱼咬钩提竿） |
| `1`–`9`, `0` / 鼠标滚轮 | 切换工具栏与种子 |
| `B` / `C` / `F` / `I` | 分别打开 商店 / 厨房 / 图鉴 / 花篮背包 |
| `M` / `Esc` | 开关音效 / 关闭弹窗或取消钓鱼 |

> **手机与平板**：点击地图任意位置自动寻路交互；在顶部 `⚙️ 设置` 中可开关虚拟方向键与行动按钮；钓鱼时按住屏幕或专属「按住拉杆」按钮控制绿条收线。

### ☁️ 开启 Google 云存档（可选）

如需跨设备同步进度，可在游戏顶部点击 **💾 存档**，填入自己在 [Google Cloud Console](https://console.cloud.google.com/) 创建的 **OAuth 2.0 Web Client ID**：

1. 在 Google Cloud Console 启用 **Google Drive API**。
2. 创建 Web 应用类型的 OAuth 2.0 客户端 ID，并将站点域名（例如 `https://linxianying.github.io`）加入 **Authorized JavaScript origins**。
3. 在游戏存档弹窗中填入 Client ID 并登录 Google 账号即可上传、恢复或开启自动云同步（仅访问私密 `drive.appdata` 空间，不会读取 Drive 中的其他文件）。


### 🚀 本地运行

直接用现代浏览器打开 `index.html` 即可游玩（无需构建步骤）。如需体验 **PWA 离线缓存** 或 **Google 云同步**，建议通过本地静态服务器或 GitHub Pages（HTTPS）访问：

```bash
python3 -m http.server 8000
# 在浏览器访问 http://localhost:8000
```

## 🇬🇧 English

A cozy storybook watercolor farming, fishing, ranching, and cooking game playable directly in the browser — featuring **custom start setup, 4 seasons & dynamic weather, lotus pond fishing (with ultra-rare Mythic fish), rare mutant flora, 26 cottage recipes (including Supreme dishes), Polaroid keepsake photo & sharing, a 64-entry interactive Almanac, farm pets, a sunny pasture, bilingual ZH/EN UI, mobile touch controls, offline PWA support, and Google Drive cloud save**.

### ✨ Features

- **🎨 Start Setup Popup & Unified Settings**
  - New farms open with a centered customization dialog to pick a **Girl / Boy** character with **4 countryside outfits each**, **4 cottage styles** (Terracotta Cream, Forest Sage, Lavender Storybook, Honey Thatch), and **3 farm map layouts** (Pond Right, Pond Left, Central Creek) with live preview.
  - Keeps the main HUD clean during play — appearance changes, language, sound, and touch controls are tucked neatly inside the top **⚙️ Settings** popup.
- **🏡 Home Farm**
  - Till soil and grow **10 crops** (Turnip, Wheat, Radish, Carrot, Tomato, Sweet Corn, Strawberry, Blueberry, Pumpkin, Starfruit) with regrowing bushes for Tomato, Corn, Strawberry, and Blueberry.
  - Upgrade your **Hoe** and **Watering Can**, clear weeds with the **Scythe**, and place **Auto-Sprinklers** and glowing evening **Garden Lanterns**.
- **🌸 4 Seasons & 5 Dynamic Weathers**
  - **Spring, Summer, Autumn, and Winter** (14 days each) with seasonal bonus crops (+20% value), watercolor palettes, and ambient particles (petals, fireflies, autumn leaves, winter snow).
  - **5 weather types** (Sunny, Cloudy, Breezy, Rainy, Snowy) with next-day forecasts; rainy days auto-water crops alongside smooth dawn → noon → dusk → night lighting.
- **🎣 Lotus Pond Fishing (17 Species + 3 Ultra-Rare Mythic Fish)**
  - Cast your line for **17 hand-painted watercolor species** across Common (4), Uncommon (4), Rare (4), Legendary (2), and **✨ Mythic (3)** tiers (**Celestial Rainbow Koi, Crystal Dragonfish, Phoenix Arowana**) with season/weather/time conditions and personal weight records.
  - Mythic fish appear at very low odds and are protected from generic fish recipe tags so you never accidentally cook them in everyday dishes.
- **🌸 Ultra-Rare Mythic Mutant Flora**
  - Harvesting any ripe crop carries a small probability of triggering a botanical miracle, spawning **4 Mythic Mutant Plants** (**Crystal Rose, Golden Wheat Crown, Moonlight Dewberry, Astral Snow Lotus**) with bespoke watercolor art and high-tier culinary uses.
- **🍳 Cottage Kitchen & 26 Recipes (4 Supreme Dishes + Chef's Miracle)**
  - Filter recipes across **All / Savory / Seafood / Sweets / 👑 Supreme**.
  - Craft **4 Supreme Dishes** (**Astral Blossom Elixir, Phoenix Imperial Pot, Celestial Royal Sashimi, Pocket Valley Miracle Feast**) using Mythic Fish and Mutant Flora; cooking regular recipes also has a small chance of triggering **✨ Chef's Miracle** (+1 bonus dish!).
- **📸 Polaroid Keepsake Photo & Sharing**
  - Catching a Mythic Fish, discovering a Mythic Plant, crafting a Supreme Dish, or triggering a Chef's Miracle automatically opens a **Storybook Polaroid Keepsake** modal — combining a live snapshot of your farm with HD watercolor artwork, date/weather postmark, and stats.
  - Supports **re-snapping with shutter sound & flash, saving high-res `720×480` PNG postcards, copying share text/image to clipboard, and native Web Share** (with graceful desktop fallback). You can also re-snap any unlocked entry from its Almanac detail page.
- **📖 Interactive Illustrated Almanac (64 Entries)**
  - Click **📖 Almanac** (or press `F`) to track overall completion across **4 tabs** (**🐟 Fish 17 · 🍳 Recipes 26 · 🌱 Flora 14 · 🐮 Ranch & Pets 7**). Click any card to inspect full details, cross-linked recipes, one-click cooking, and Polaroid photo sharing.
- **🐾 Farm Pets & 🐮 Sunny Pasture**
  - Adopt a free **Calico Cat, Corgi, or Lop Bunny** companion, and head through the East Gate to raise **Chickens, Ducks, Sheep, and Cows** for daily Eggs, Duck Eggs, Wool, and Fresh Milk.
- **💾 Dual Local Backup & Google Drive Cloud Sync**
  - Auto-saves within 1 second to both `localStorage` and `IndexedDB`, with JSON export/import and optional Google Drive (`appDataFolder`) sync using your own OAuth Client ID.
- **📱 Mobile Friendly, Offline PWA & Bilingual UI**
  - Tap-to-walk navigation, toggleable virtual D-pad, self-hosted `tailwindcss.js`, `manifest.json`, and `sw.js` for zero-CDN offline play, plus one-click `中文 / EN` switching in **⚙️ Settings**.

### 🎮 Controls

| Key / Input | Action |
| --- | --- |
| `WASD` / `Arrow Keys` / Click Map | Walk & click-to-walk auto-interact |
| `Left-Click` / `Space` | Use active tool (till, water, plant, cast line, hold to reel) |
| `E` / `Right-Click` | Smart interact (harvest, collect drops, pet animals/pets, enter buildings, hook fish) |
| `1`–`9`, `0` / Mouse Wheel | Switch hotbar tools & seeds |
| `B` / `C` / `F` / `I` | Open Shop / Kitchen / Almanac / Satchel |
| `M` / `Esc` | Toggle sound / Close modal or cancel fishing |

> **Mobile & Tablet**: Tap anywhere on the map to walk and interact; toggle the on-screen D-pad inside **⚙️ Settings**; hold the screen or dedicated reel button while fishing.

### ☁️ Optional Google Cloud Sync

To sync saves across devices, click **💾 Save** in the top bar and enter an **OAuth 2.0 Web Client ID** created in [Google Cloud Console](https://console.cloud.google.com/):

1. Enable the **Google Drive API** in Google Cloud Console.
2. Create an OAuth 2.0 Client ID (Web application) and add your site origin (e.g., `https://linxianying.github.io`) under **Authorized JavaScript origins**.
3. Paste the Client ID in the game's Save modal and sign in with Google to upload, restore, or enable auto-sync (uses private `drive.appdata` only; never accesses other Drive files).
